# Pulse (Bonch AutoCheck)

Минималистичный Android-клиент для личного кабинета СПбГУТ (`lk.sut.ru`) с фоновой автоотметкой на парах, расписанием семестра, дневником, сообщениями и файлами группы.

---

## Возможности

| Раздел | Что умеет |
| :--- | :--- |
| **Сегодня** | Автоотметка по расписанию и правилам, ручная отметка в один тап, отображение текущей пары и заметок на сегодня. |
| **Расписание** | Все недели семестра в единой вертикальной ленте, календарь по месяцам, преподаватели и кабинеты, фильтр по типам пар (Лекция / Практика / Лаба) и личные заметки к любому дню. |
| **Сообщения и файлы** | Входящие сообщения из ЛК в хронологическом порядке с датой, временем и вложениями, отправка ответов (включая файлы до 5 МБ), а также скачивание файлов группы. |
| **Дневник** | Кольцевая статистика посещаемости, переключатель учёта пропусков по болезни и уважительной причине (`Б` / `У`), тип пары для каждого пропуска, оценки со средним баллом по каждому предмету, аттестации и зачёты. |
| **Фоновая служба** | Показывает в постоянном уведомлении следующую пару и кабинет, спит между парами и приостанавливает фоновую синхронизацию ночью (`23:00–07:00`) для экономии заряда и запросов. |
| **Интерфейс и обновления** | Светлая, тёмная и системная темы, плавные свайпы между вкладками за пальцем, автоматическая проверка новых APK-релизов на GitHub. |

---

## Приватность и принцип работы

- **Без собственного сервера.** Приложение не использует промежуточный бэкенд — все запросы идут напрямую с твоего телефона на `lk.sut.ru`.
- **Локальное хранение.** Логин, пароль и cookies хранятся только в приватном хранилище устройства и полностью удаляются при выходе из аккаунта.
- **Нужен интернет.** Поскольку отметки отправляются прямо с телефона, для работы фоновой автоотметки устройство должно быть подключено к сети.
- **Одна сессия ЛК.** `lk.sut.ru` поддерживает одну активную сессию одновременно. Pulse переиспользует сохранённые cookies, чтобы не делать лишних повторных входов, но вход с ПК или другого браузера сбросит текущую сессию в приложении (при следующей проверке Pulse переподключится автоматически).

## Установка и обновления

1. Перейди в раздел **Releases** основного репозитория: [daniilxfk62-ctrl/bonch-autocheck](https://www.google.com/search?q=https://github.com/daniilxfk62-ctrl/bonch-autocheck/releases) (или запасного: [g1tm4estr0/bonch-autocheck](https://www.google.com/search?q=https://github.com/g1tm4estr0/bonch-autocheck/releases)).
2. Скачай последний файл `BonchAutoCheck-*.apk` и установи его на Android-смартфон (`Android 7.0+`).
3. После установки приложение само проверяет выход новых версий в обоих репозиториях (приоритет у основного) и предлагает скачать обновление прямо из интерфейса.

> **Подсказка при первом входе:** если `lk.sut.ru` перегружен и вход не прошёл с первого раза, просто попробуй нажать «Войти» ещё раз. Сразу после входа приложение загрузит расписание семестра в фоне.

## Архитектура и структура проекта

Приложение построено на связке **нативного Android-сервиса (Java)** и **локального WebView-интерфейса (`assets/index.html`)**, общающихся через `AndroidBridge`. Сборка выполняется напрямую через Android SDK CLI без Gradle.

```text
.
├── AndroidManifest.xml                  # Манифест (minSdk 24, targetSdk 33, :bg_daemon)
├── .github/workflows/build.yml          # Автосборка APK через aapt2, javac, d8, apksigner
├── assets/
│   └── index.html                       # Мобильный интерфейс Pulse (HTML/CSS/JS)
├── res/
│   ├── drawable/                        # Векторные иконки Pulse и статус-бара
│   ├── mipmap-anydpi/                   # Fallback-иконки для Android 7
│   ├── mipmap-anydpi-v26/               # Адаптивные и монохромные иконки (Android 8–15)
│   └── values/strings.xml               # Название приложения
└── src/ru/sut/bonch/
    ├── MainActivity.java                # WebView, AndroidBridge, скачивание файлов и APK
    ├── BonchBackgroundDaemon.java       # Фоновая служба, watchdog, дневной цикл синхронизации
    ├── SutApiClient.java                # Прямой HTTP/cookie-клиент к lk.sut.ru
    ├── ScheduleManager.java             # Парсинг расписания семестра и автоотметка (open_zan)
    ├── DiaryMonitor.java                # Парсинг jurnal_dnevnik.php (посещаемость и оценки)
    ├── MessageManager.java              # Личные сообщения (sendto2.php) и файлы группы
    ├── AppStorage.java                  # Локальное JSON-хранилище и межпроцессные логи
    ├── NotificationHelper.java          # Постоянное уведомление (BigTextStyle) и алерты
    ├── UpdateChecker.java               # Проверка релизов по двум GitHub-репозиториям
    └── BootReceiver.java                # Автозапуск фоновой службы после перезагрузки
```

## Сборка из исходников

В репозитории настроен GitHub Actions workflow `.github/workflows/build.yml`: при каждом `push` в `main`/`master` или создании тега `v*` он автоматически компилирует ресурсы (`aapt2`), Java-классы (`javac` / `d8`), выравнивает и подписывает APK (`zipalign` / `apksigner`), после чего публикует артефакт в **GitHub Releases**.
