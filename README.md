**Pulse** — быстрый и спокойный клиент для личного кабинета СПбГУТ (`lk.sut.ru`). Он заменяет перегруженный веб-интерфейс нативным приложением с фоновой автоотметкой, расписанием на весь семестр, дневником, сообщениями преподавателей и файлами группы — в чистом минималистичном стиле и без единого стороннего сервера.

## Возможности

| Раздел | Описание |
| :--- | :--- |
| **Сегодня и автоотметка** | Живой монитор состояния службы, ручная и фоновая автоотметка с естественной задержкой (`Сразу`, `+2 мин`, `1–4 мин`), раздельные правила по предметам и типам пар (`Лекция`, `Практика`, `Лаба`), автоматическая пауза ночью (`23:00–07:00`). |
| **Расписание** | Непрерывная вертикальная лента по дням с боковой шкалой недели, цветовые акценты по типам занятий, порядковый счётчик пар в семестре (`N/M`, `Последняя`), календарь семестра, бейджи пропусков (`Н`, `Б`, `У`) и оценок из дневника прямо на карточках. |
| **Умные подгруппы** | Определение наслоенных пар и выбор одного или нескольких преподавателей. Одиночные пары без пересечения по времени не скрываются — фильтр срабатывает только в конфликтных слотах. |
| **Хаб предмета** | Полноэкранная карточка дисциплины: ближайшая пара этого типа, посещаемость и средний балл, список всех преподавателей с быстрым переходом в чат и фильтрация файлов группы по авторам. |
| **Заметки** | Привязка заметок к дате, выбор времени (`Утром` или интервал `С — до`), системные напоминания через `AlarmManager` и резервная копия в JSON. |
| **Сообщения и файлы** | Полноэкранные чаты с преподавателями, разделители по датам, полная загрузка текста писем, вложения до 5 МБ, создание нового письма и раздел «Файлы группы» с поиском и скачиванием. |
| **Дневник** | Кольцо общей посещаемости, средний балл, переключатель учёта уважительных пропусков (`Б` и `У`), раздельные строки промежуточной аттестации и итогового контроля (`Зачёт`, `Зачёт с оценкой`, `Экзамен`). |
| **Интерфейс** | Светлая, тёмная и системная темы с адаптивным статус-баром, горизонтальные свайпы между разделами и встроенная проверка обновлений из GitHub Releases. |

## Приватность и архитектура

```text
Устройство (Pulse) ──────── HTTPS ────────▶ lk.sut.ru
```

- **Zero-Server.** У приложения нет собственного сервера, облачных баз данных, аналитики и телеметрии.
- **Локальное хранение.** Логин, пароль, cookies, кэш расписания и заметки хранятся только в памяти телефона.
- **Cookie-first.** Pulse переиспользует текущую сессию `lk.sut.ru` и не выполняет лишних повторных входов.
- **Прямое соединение.** Для автоотметки на устройстве необходим доступ в интернет, а скорость ответа зависит от работы сайта `lk.sut.ru`.

## Установка

1. Скачайте **`BonchAutoCheck-02.09.07.apk`** из раздела [Releases](https://www.google.com/search?q=https://github.com/daniilxfk62-ctrl/bonch-autocheck/releases/latest) (или запасного репозитория [g1tm4estr0/bonch-autocheck](https://www.google.com/search?q=https://github.com/g1tm4estr0/bonch-autocheck/releases/latest)).
2. Установите приложение (поддерживается Android 7.0 и выше, целевой SDK — **Android 15 / API 35**).
3. Выдайте разрешение на уведомления и отключите оптимизацию батареи для **Pulse**, чтобы система не останавливала фоновую службу.
4. Войдите в аккаунт `lk.sut.ru` и выберите нужные правила по предметам и подгруппам в разделе «Настройки».

> Начиная с версии **02.09.07**, релизные APK подписываются постоянным ключом — последующие обновления устанавливаются поверх без удаления приложения и потери заметок.

## Версия для iPhone

**Статус:** обновление для iOS в разработке.

Порт для iPhone строится по тому же принципу **Zero-Server** — без стороннего сервера и без Mac:

- Единый интерфейс (`index.html`) в формате **Standalone PWA** с установкой на экран «Домой» через Safari.
- Локальная синхронизация и автоотметка через **Apple Команды (Shortcuts)** и системные автоматизации iOS.
- В текущем обновлении переносится актуальный бэкенд версии `02.09.07`: полная подгрузка текста сообщений, умные подгруппы, обновлённый парсер дневника и заметки.

## Частые вопросы

**Сильно ли фоновая автоотметка расходует заряд?**
Нет. Служба не держит экран и не опрашивает сервер постоянно — между парами она находится в режиме ожидания и активируется только к началу выбранных занятий. С 23:00 до 07:00 фоновая синхронизация приостанавливается.

**Сбрасывается ли сессия в ЛК на компьютере?**
Сайт `lk.sut.ru` поддерживает только одну активную сессию одновременно. Pulse переиспользует сохранённые cookies, но вход в ЛК с ПК сбрасывает сессию на телефоне — при следующей проверке Pulse снова авторизуется.

**Почему при первом входе расписание загружается несколько секунд?**
После первого входа приложение сканирует весь семестр, дневник, сообщения и файлы напрямую с `lk.sut.ru`. Если сервер вуза в этот момент перегружен, повторите вход или потяните экран вниз для обновления.

**Как перенести заметки на другое устройство?**
Откройте «Настройки → Резервная копия заметок», скопируйте JSON и импортируйте его на новом устройстве.

## Сборка из исходников

Сборка выполняется без Gradle напрямую через Android SDK build-tools (`aapt2` → `javac` → `d8` → `zipalign` → `apksigner`) с помощью workflow `.github/workflows/build.yml` на **Java 17** и **Android SDK 35**.

Для автоматической подписи релизов в GitHub Actions добавьте в `Settings → Secrets and variables → Actions`:

- `KEYSTORE_BASE64` — файл `.keystore` в кодировке Base64
- `KEYSTORE_PASSWORD` — пароль хранилища
- `KEY_PASSWORD` — пароль ключа
