**Pulse** — это быстрый и лёгкий клиент для личного кабинета СПбГУТ (`lk.sut.ru`), созданный студентами для студентов. Вместо медленного веб-интерфейса и постоянной проверки кнопки «Начать занятие» вы получаете нативное приложение с фоновой автоотметкой, расписанием на весь семестр, дневником, сообщениями преподавателей и файлами группы — в чистом минималистичном интерфейсе с плавной физикой и без единого стороннего сервера.

## 🔒 Приватность и архитектура

```text
  📱 Твой телефон (Pulse)  ─────── прямой HTTPS ───────▶  🌐 lk.sut.ru
```

- **Zero-Server:** у Pulse нет собственного бэкенда, облачных баз данных, аналитики или телеметрии.
- **Всё остаётся на устройстве:** логин, пароль, cookies, расписание и заметки хранятся исключительно в локальной памяти телефона.
- **Cookie-first:** приложение переиспользует активную сессию `lk.sut.ru` и не делает лишних повторных авторизаций.
- **Важно:** поскольку запросы идут напрямую с устройства, **для автоотметки обязательно нужен интернет**, а скорость отклика зависит от работы самого сайта `lk.sut.ru`.

## 📲 Установка (Android)

1. Откройте раздел **\[suspicious link removed\]** и скачайте свежий **`BonchAutoCheck-02.09.07.apk`**.
2. Установите APK на устройство (Android 7.0 и выше, целевой SDK — **Android 15 / API 35**).
3. При первом запуске:
   - Разрешите уведомления (чтобы получать статусы автоотметки, новых сообщений и напоминаний по заметкам).
   - Отключите оптимизацию батареи для **Pulse**, чтобы система не останавливала фоновую службу в спящем режиме.
4. Войдите под данными от `lk.sut.ru` и настройте правила по предметам и подгруппам в разделе **«Настройки»**.

> [!TIP]
> Начиная с версии **02.09.07**, релизные APK подписываются постоянным ключом — все будущие обновления будут устанавливаться поверх старой версии без потери настроек и заметок.

## ❓ Частые вопросы

&lt;details&gt;
&lt;summary&gt;&lt;b&gt;Сильно ли фоновая автоотметка тратит батарею?&lt;/b&gt;&lt;/summary&gt;
&lt;br /&gt;
Нет. Служба не держит экран и не опрашивает сервер непрерывно — между парами она спит и просыпается только к началу выбранных занятий, а ночью (с 23:00 до 07:00) фоновая синхронизация полностью приостанавливается.
&lt;/details&gt;

&lt;details&gt;
&lt;summary&gt;&lt;b&gt;Сбрасывается ли сессия в ЛК на компьютере?&lt;/b&gt;&lt;/summary&gt;
&lt;br /&gt;
Сайт &lt;code&gt;lk.sut.ru&lt;/code&gt; поддерживает только одну активную сессию одновременно. Pulse максимально бережно переиспользует cookies, но если вы зайдёте в ЛК с ПК, сессия в приложении сбросится — и при следующей проверке Pulse снова авторизуется (тогда на ПК потребуется войти заново).
&lt;/details&gt;

&lt;details&gt;
&lt;summary&gt;&lt;b&gt;Почему при первом входе данные грузятся не мгновенно?&lt;/b&gt;&lt;/summary&gt;
&lt;br /&gt;
Сразу после первого входа приложение сканирует расписание на весь семестр, дневник, сообщения и файлы напрямую с &lt;code&gt;lk.sut.ru&lt;/code&gt;. Если сервер вуза в этот момент перегружен, просто повторите вход или потяните экран вниз для обновления.
&lt;/details&gt;

&lt;details&gt;
&lt;summary&gt;&lt;b&gt;Как перенести заметки на другой телефон?&lt;/b&gt;&lt;/summary&gt;
&lt;br /&gt;
Откройте &lt;b&gt;Настройки → Резервная копия заметок&lt;/b&gt;, скопируйте JSON и вставьте его на новом устройстве.
&lt;/details&gt;

## 🛠️ Сборка из исходников

Проект собирается без Gradle — напрямую через Android SDK build-tools (`aapt2` → `javac` → `d8` → `zipalign` → `apksigner`) с помощью готового workflow [.github/workflows/build.yml](https://www.google.com/search?q=.github/workflows/build.yml) на **Java 17** и **Android SDK 35**.

Для автоматической подписи релизов в GitHub Actions задайте в `Settings → Secrets and variables → Actions`:
- `KEYSTORE_BASE64` — ваш `.keystore` в формате Base64
- `KEYSTORE_PASSWORD` — пароль хранилища
- `KEY_PASSWORD` — пароль ключа
